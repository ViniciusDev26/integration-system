# Architecture Decision Records (ADRs) — web

Front-end decisions for `apps/web` (the Vite SPA) live here.

**None yet.** The app is currently the default Vite React + TypeScript scaffold.
Front-end decisions (routing, data fetching, state, the persistent player,
styling, testing, dev proxy vs. Vite middleware) will be recorded here as they
are made — do not create ADRs speculatively.

Repo-wide decisions live in [`/docs/adrs`](../../../../docs/adrs/); the decision
to go SPA (Vite + React) and the API/serving split will be captured as we build
it out.
